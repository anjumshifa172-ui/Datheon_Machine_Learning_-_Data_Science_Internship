# Machine Learning and Data Science Internship

## Overview
This repository contains three completed projects as part of my Machine Learning and Data Science Internship at Datheon.

## Completed Projects

### Task 1: Iris Flower Classification
- Dataset: Iris dataset
- Goal: Classify iris flowers into different species.
- Algorithms: Logistic Regression and Decision Tree.
- Evaluation: Accuracy, confusion matrix and classification report.

### Task 2: House Price Prediction
- Dataset: California Housing dataset
- Goal: Predict house prices using machine learning.
- Algorithms: Linear Regression and Decision Tree.
- Evaluation: MAE, MSE, RMSE and R² score.

### Task 3: Customer Churn Prediction
- Dataset: Telco Customer Churn dataset
- Goal: Predict whether customers are likely to leave a telecom service.
- Algorithms: Random Forest and XGBoost.
- Evaluation: Accuracy, Precision, Recall, F1-score, ROC-AUC and cross-validation.
